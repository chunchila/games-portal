# דינו Merge - גן האבולוציה

משחק מיזוג בעברית, בקובץ HTML יחיד. איורי SVG מקוריים, ללא ספריות, התקנות או נכסים חיצוניים.

## משחק חי
https://dino-games-q4b7d1pa3-romans-projects-97b8739c.vercel.app/

## איך משחקים
- נוגעים בשתי ביצים זהות או גוררים אחת לשנייה כדי לגלות דינוזאור.
- מזגים שני דינוזאורים זהים למין הבא: 13 תגליות, מביצת מסתורין עד טי־רקס אגדי.
- דינוזאורים מייצרים מטבעות אוטומטית. במטבעות קונים ביצים נוספות.
- משימות מיזוג ובונוסים על גילוי חדש נותנים עוד מטבעות.
- באלבום מחכים כל המינים שטרם נפתחו מאחורי סימני שאלה.
- אפשר להזיז יצורים למשבצות ריקות, או לבקש סימון של זוג מתאים.

## שמירה ותאימות
- מובייל, טאבלט ומחשב, עברית RTL, תמיכה בלחיצה ובגרירה.
- שמירה אוטומטית ב-localStorage בדפדפן ובמכשיר הנוכחיים בלבד.
- הכנסה מחוץ למשחק עד 8 שעות. ניקוי נתוני האתר מוחק את השמירה.
- צליל סינתטי אופציונלי, מכובה כברירת מחדל.
- ללא פרסומות, רכישות אמיתיות או מעקב שהוסף במשחק.
- שרשרת המיזוג היא דמיונית, לא תיאור מדעי של אבולוציה. הפטרנודון הוא זוחל מעופף.

## הפעלה מקומית
פותחים את `index.html` בדפדפן מודרני. לשמירה עקבית מומלץ שרת מקומי, לדוגמה `python -m http.server 8000`.

הקישור החי הוא deployment עצמאי של Vercel בפרויקט קיים, לא החלפה של אתר ה-production.
