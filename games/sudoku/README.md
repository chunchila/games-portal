# סודוקו מאסטר 9️⃣

לוחות סודוקו אינסופיים עם פתרון יחיד מובטח, בשלוש רמות קושי.

## איך משחקים
- גנרטור עם בדיקת יחידות פתרון (backtracking + ספירת פתרונות)
- מצב עיפרון לרשימות, הדגשת שורה/עמודה/ריבוע/מספרים זהים
- 3 טעויות מותרות, טיימר, שיא זמן לכל רמה, מקלדת נתמכת

## טכנולוגיה
HTML/CSS/JS טהור בקובץ יחיד, RTL, מותאם מובייל.
