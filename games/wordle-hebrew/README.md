# וורדל בעברית

פאזל מילים יומי בעברית, במשחק HTML אחד בלי תלויות. נחשו את המילה בת חמש האותיות תוך שישה ניסיונות.

**🎮 משחקים: https://wordle-hebrew.vercel.app**

## תכונות

- מילה יומית אחת, זהה לכל השחקנים, לפי התאריך (מתחלפת בחצות לפי שעון המכשיר)
- שישה ניסיונות, צביעה בירוק / צהוב / אפור, כולל טיפול נכון באותיות כפולות
- עברית מלאה מימין לשמאל, מקלדת על המסך ותמיכה במקלדת פיזית (גם כשהמקלדת באנגלית)
- אנימציית היפוך אריחים, רעד על קלט לא חוקי, בדיקת מילה מול מילון
- סטטיסטיקה ב-localStorage: משחקים, אחוז נצחונות, רצף נוכחי, שיא רצף והתפלגות ניחושים
- שיתוף תוצאה באימוג'י 🟩🟨⬜ עם מספר היום (שיתוף מערכתי בנייד, העתקה ללוח בדסקטופ)
- מצב תרגול חופשי עם מילים אקראיות
- ערכת נושא בהירה/כהה ומצב ניגודיות גבוהה

## אותיות סופיות

ך ם ן ף ץ נחשבות כאותיות הרגילות שלהן (כ מ נ פ צ), ומוצגות בצורה הסופית בסוף המילה.

## הרצה מקומית

פותחים את `index.html` בדפדפן. אין שלב בנייה.

## בדיקה

אפשר לפתוח יום מסוים עם `?day=מספר`, למשל `index.html?day=5`.
