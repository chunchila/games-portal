# ☕ בית הקפה שלי — משחק מיזוג (Merge-2)

משחק מיזוג בעברית (RTL), בקובץ HTML יחיד, בפוליש גבוה ומותאם למובייל. מכילים את בית הקפה והמאפייה שלכם: ממזגים פריטים, משרתים לקוחות ומשלימים את אלבום האספנות.

## 🎮 משחק חי

**[לחצו כאן לשחק](https://dino-games-p26azxrmz-romans-projects-97b8739c.vercel.app)**

## איך משחקים

- **מיזוג** — גוררים פריט על פריט זהה כדי למזג אותם לפריט ברמה גבוהה יותר (או מקישים על פריט ואז על היעד).
- **גנרטורים** — מכונת הקפה 🤎 והתנור 🔥 מייצרים פריטים בסיסיים בעלות של אנרגיה ⚡.
- **לקוחות** — מזמינים פריטים ומשלמים במטבעות 🪙 ובאנרגיה. גוררים אליהם את הפריט שהזמינו.
- **אלבום אספנות 📖** — גלו את כל שרשראות המיזוג: שרשרת הקפה (מפולי קפה ועד קפה אלופים 🏆) ושרשרת המאפייה (מקמח ועד עוגת אלופים 🎂).
- **חנות 🛒** — קנו אנרגיה ופריטים במטבעות שצברתם.
- **שמירה אוטומטית** — כל ההתקדמות נשמרת ב-localStorage, כולל צבירת אנרגיה גם כשהמשחק סגור.

## טכנולוגיה

HTML + CSS + JavaScript בלבד, בקובץ אחד, ללא תלות חיצונית. עובד בכל דפדפן מודרני, במובייל ובדסקטופ.
