# זרימה 🌊

משחק חשיבה: חברו כל זוג נקודות באותו צבע בקו רציף, בלי הצטלבויות, תוך כיסוי כל משבצות הלוח.

## איך משחקים
- 17 שלבים (5×5 עד 7×7), כולם עם פתרון מובטח (נוצרו פרוצדורלית כחלוקת לוח מלאה)
- גרירה מנקודה לנקודה, גרירה אחורנית למחיקה, נגיעה בקו אחר חותכת אותו
- דירוג 1-3 כוכבים לפי מספר מהלכים, התקדמות נשמרת מקומית

## טכנולוגיה
HTML/CSS/JS טהור, ציור על Canvas, RTL, מותאם מובייל.
