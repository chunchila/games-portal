# מלכודות! 🚪

פלטפורמר מרמה בעברית (RTL), בקובץ HTML יחיד. נראה תמים - הוא לא.

**🎮 משחק חי:** https://malchodot.vercel.app/

## מה יש במשחק

- 30 שלבים קצרים שנראים פשוטים, ומרמים בדיוק ברגע הלא נכון
- מלכודות: הרצפה נופלת, קוצים צצים, הדלת בורחת, התקרה יורדת, הכבידה מתהפכת
- כל מוות מלמד את המלכודת - נקודות ביקורת (דגלים) שומרות את המקום
- ספירת מוותים, בחירת שלב, וסוף מצחיק
- שמירת התקדמות אוטומטית ב-localStorage
- מותאם למובייל (כפתורי מגע) ולמקלדת (חצים / רווח)

## איך משחקים

הגע לדלת הזהובה. זהו. או שלא.

| פעולה | מקלדת | מגע |
|-------|--------|------|
| תנועה | חצים / A,D | כפתורי חצים |
| קפיצה | רווח / W / חץ למעלה | כפתור קפיצה |

## הפעלה מקומית

פשוט פתחו את `index.html` בדפדפן. אין תלויות, אין build, אין תירוצים.
