# פיצוץ בלוקים - Block Puzzle בעברית

משחק פאזל בסגנון Block Blast, קובץ HTML יחיד, עברית RTL, מותאם למובייל (גרירה במגע) ולמחשב (עכבר).

**🎮 שחקו עכשיו:** https://dino-games-4xw0fel3r-romans-projects-97b8739c.vercel.app/

## איך משחקים
- לוח 8x8 ושלוש צורות בכל סבב. גוררים כל צורה אל הלוח.
- שורה או עמודה מלאה מתפוצצת ונותנת נקודות.
- פיצוץ כמה קווים יחד, או פיצוצים ברצף, נותנים קומבו ובונוס. לוח נקי נותן +300.
- נגמר המקום לכל הצורות - המשחק נגמר.

## מצבים
- **קלאסי** - אינסופי, עם שיא שנשמר.
- **שלבים** - 12 שלבים עם מטרות (נקודות, קווים, פיצוצים כפולים, קומבו), עם דירוג כוכבים.

## מאפיינים
- אנימציות פיצוץ, חלקיקים, רעידת מסך וטקסט קומבו
- צלילים ורטט (אפשר להשתיק)
- שיאים והתקדמות בשלבים נשמרים ב-localStorage
- ללא תלויות וללא בנייה: פשוט פותחים את `index.html`

## הרצה מקומית
פתחו את `index.html` בדפדפן.
