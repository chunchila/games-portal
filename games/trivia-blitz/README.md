# בזק טריוויה ⚡

משחק טריוויה מהיר בעברית: 60 שניות, כמה שיותר תשובות נכונות.

## איך משחקים
- 60 שניות על השעון, שאלות מ-10 קטגוריות (גאוגרפיה, מדע, היסטוריה, ישראל, טבע, ספורט, תרבות, קולנוע, אוכל, ידע כללי)
- תשובה נכונה: 10 נקודות. רצף של 5 מכפיל ×2
- טעות: מינוס 3 שניות
- סטטיסטיקות בסוף: נכונות, טעויות, רצף שיא, אחוז דיוק + שיא אישי ושיתוף

## טכנולוגיה
HTML/CSS/JS טהור בקובץ יחיד, ללא תלויות. RTL מלא, מותאם מובייל.
