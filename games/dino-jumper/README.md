# דינוש הקפצן 🦖

פלטפורמר side-scroller בהשראת הז'אנר הקלאסי, אבל מקורי לגמרי: גיבור דינוזאור ירוק עם סרט ראש אדום שרץ, קופץ על יצורים קומיים, אוסף שקלים ועצמות, שובר לבנים, ובסוף מתמודד עם **הפקיד הראשי** ועם טופס 17.

**משחק חי:** https://dino-games-l3id4nr01-romans-projects-97b8739c.vercel.app/

קובץ HTML יחיד (`index.html`), בלי ספריות ובלי נכסים חיצוניים. כל הציור והצלילים נוצרים בקוד. אין שום דמות, מוזיקה או נכס של נינטנדו.

## שליטה

| | מקלדת | מגע |
|---|---|---|
| תנועה | חצים או A / D | כפתורי חצים |
| קפיצה | רווח, חץ למעלה או W | כפתור "קפוץ!" |
| השהיה | P או Esc | כפתור "השהה" |
| צליל | M | כפתור "צליל" |

## שלבים

1. **גן הפלאפל** - "הכול מטוגן, כלום לא קל". פלאפלונים עצבניים. אפשר לדרוך עליהם.
2. **מערת הבירוקרטים** - "כאן כל פתח דורש אישור משלוש חותמות". קיפודי שניצל (אסור לדרוך!) ויתושי בירוקרט ("תחזור מחר").
3. **הר הגעש של השווארמה** - "חם פה. אפילו השיפוד לא מאמין". בורות רחבים, לבה ואויבים בצפיפות.
4. **משרד הרישוי העליון** - קרב מול הפקיד הראשי: דורסים אותו על הראש שלוש פעמים ומתחמקים מטפסים מעופפים.

## מכניקה

- דריכה על אויב, שבירת לבנים מלמטה, בלוקי "?" עם שקלים.
- סופגנייה נותנת מגן סוכר שסופג פגיעה אחת.
- 25 שקלים = חיים נוספים. שלוש עצמות בכל שלב, ובונוס על איסוף מלא.
- נקודות ביקורת, שלוש חיים, ושיא שנשמר בדפדפן.

## שיאים

השיא, מספר העצמות והשלב האחרון נשמרים ב-`localStorage` תחת המפתח `dinush-hakfatzan-v1`.

## הרצה מקומית

פותחים את `index.html` בדפדפן. זה הכול.
