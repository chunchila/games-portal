# חשבון בזק 🔢

60 שניות של תרגילי חשבון ברמת קושי עולה.

## איך משחקים
- תשובה נכונה: 10 נקודות + בונוס רצף; טעות: מינוס 2 שניות
- ארבע פעולות, רמת הקושי עולה ככל שפותרים נכון
- שליחה אוטומטית כשהתשובה הנכונה הוקלדה, מקלדת נתמכת

## טכנולוגיה
HTML/CSS/JS טהור בקובץ יחיד, RTL, מותאם מובייל.
