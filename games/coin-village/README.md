# כפר המטבעות 🎰🏘️

משחק דפדפן בסגנון **Coin Master** - קובץ HTML יחיד, בעברית מלאה עם תמיכת RTL, מותאם למובייל. בלי שרת, בלי התקנות - פותחים ומשחקים.

## איך משחקים?

כל סיבוב עולה ספין אחד ⚡. ספינים מתמלאים מעצמם - ספין חדש כל דקה (עד 50).

### 🏘️ בניית הכפר
קנה ושדרג 5 מבנים (בית מגורים, חווה, שוק, מגדל שמירה ופסל הזהב), שלוש רמות לכל מבנה. משלימים את הכפר ➡️ עוברים לכפר הבא עם בונוס ענק. 6 כפרים בסך הכל, מהחקלאים ועד ממלכת הזהב.

### 🔨 התקפות ושוד
- **שלושה פטישים** פותחים התקפה: בחר מטרה בכפר היריב ושלל מטבעות - אבל תיזהר ממגנים ומהריסות.
- **שלושה חזירים** פותחים שוד: בחר איפה לחפור ומצא את המטמון הגדול.

### 💾 שמירה אוטומטית
כל ההתקדמות (מטבעות, ספינים, כפר, מגנים וסטטיסטיקות) נשמרת ב-localStorage של הדפדפן - אפשר לסגור ולחזור מתי שרוצים, והספינים ממשיכים להצטבר גם כשהמשחק סגור.

## 🛠️ טכנולוגיה

- HTML + CSS + JavaScript בלבד, קובץ `index.html` אחד
- אנימציות סלוט, קונפטי ומטבעות מעופפים ב-CSS/Canvas
- אפקטים קוליים ב-Web Audio API (עם כפתור השתקה)
- עיצוב mobile-first עם RTL מלא
