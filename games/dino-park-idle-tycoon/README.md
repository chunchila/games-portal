# 🦖 פארק דינו - משחק Idle Tycoon

משחק דפדפן בעברית (RTL), מותאם למובייל, בקובץ HTML יחיד ללא תלויות.

**🎮 [שחקו עכשיו](https://dino-games-rmncfhtaw-romans-projects-97b8739c.vercel.app/)** - https://dino-games-rmncfhtaw-romans-projects-97b8739c.vercel.app/

## איך משחקים
- **פותחים גידות**: טריצרטופס, ברכיוזאור, ולוצירפטור וטי-רקס. כל גידה מכניסה מטבעות בכל מחזור.
- **לוחצים על הגידה** כדי לאסוף. **מנהלים** מפעילים אותה אוטומטית.
- **שדרוגי רמה** (×1 / ×10 / ×100 / מקס׳). בכל יעד רמה (10, 25, 50, 100...) ההכנסה של הגידה מוכפלת ב-2.
- **שדרוגים** חד-פעמיים שמכפילים הכנסה לגידה אחת או לכל הפארק.
- **הכנסה אופליין**: כשחוזרים למשחק מופיע מסך "בזמן שלא היית..." (עד 12 שעות, לגידות עם מנהל).
- **שיקום הפארק (פרסטיז')**: מאפסים את הפארק ומקבלים 🥚 ביצי דינו. כל ביצה נותנת +10% קבוע להכנסה.
- **שמירה אוטומטית** ב-localStorage.

## הרצה מקומית
פותחים את `index.html` בדפדפן. אין צורך בהתקנה.
