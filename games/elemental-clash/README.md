# קרב היסודות ⚔️

משחק קלפים מקורי נגד המחשב: ארבעה יסודות (אש, מים, אדמה, רוח), לקיחות וקופת תיקו.

## איך משחקים
- 10 קלפים לכל שחקן, בכל סיבוב שניכם שולפים בו-זמנית
- יתרון יסוד: אש>אדמה>מים>אש (+3 כוח), רוח ניטרלית
- הגבוה לוקח את הלקיחה ואת הנקודות; תיקו מעביר את הקלפים לקופה הבאה
- AI עם היוריסטיקת בחירת קלפים, מאזן ניצחונות נשמר מקומית

## טכנולוגיה
HTML/CSS/JS טהור בקובץ יחיד, RTL, מותאם מובייל.
