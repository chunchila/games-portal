# 🕹️ ארקדיה (Arcadia)

אתר-בית שמרכז את כל המשחקים שבנינו, במקום אחד.

**[🎮 לאתר החי](https://dino-games-arcadia.vercel.app)**

## מה יש כאן

- קובץ `index.html` יחיד, בלי תלויות וללא build
- עברית RTL, מובייל-פירסט
- חיפוש, סינון לפי קטגוריות ומיון "חדשים"
- כרטיס לכל משחק עם קישור למשחק החי

## הקטגוריות

מילים · טריוויה · פאזל · ארקייד · אסטרטגיה · קלפים · זיכרון · טייקון וסימולציה · מיזוג · ילדים
